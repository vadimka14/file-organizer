 ПОРТ — Программа Организации Разнообразных Типов
 
Консольная утилита на Go для автоматической сортировки файлов по типам. Программа сканирует указанную директорию, распределяет файлы по категориям (Documents, Images, Music, Video, Archives) на основе расширения, ведёт лог всех операций и формирует отчёт со статистикой.
 
## Возможности
 
- Автоматическая сортировка файлов по расширениям на основе настраиваемых правил
- Безопасное перемещение с обработкой конфликтов имён (добавление временной метки)
- Логирование всех операций (успешных и неудачных) в файл `organizer.log`
- Отчёт со статистикой: количество файлов и суммарный размер по каждой категории
- Понятные сообщения об ошибках на каждом этапе (валидация директории, доступ к файлам)
## Установка
 
```bash
git clone https://github.com/username/file-organizer.git
cd file-organizer
go build
```
 
## Использование
 
```bash
./file-organizer
```
 
Программа запросит путь к директории для организации. Если просто нажать Enter — будет использована текущая директория.
 
```
=== Файловый органайзер ===
Введите путь к директории для организации (Enter для текущей директории): /home/user/downloads
Начинаем организацию файлов...
 
=== Отчёт о перемещении файлов ===
Всего обработано файлов: 42
Общий размер: 128.50 KB
 
Статистика по категориям:
 
Documents:
  Файлов: 15, Размер: 45.30 KB
 
Images:
  Файлов: 20, Размер: 80.20 KB
 
Организация завершена! Подробности в файле organizer.log
```
 
## Структура правил сортировки
 
| Расширение | Категория |
|---|---|
| .jpg, .jpeg, .png | Images |
| .pdf, .doc, .docx, .txt | Documents |
| .mp3, .wav | Music |
| .mp4, .avi | Video |
| .zip, .rar | Archives |
